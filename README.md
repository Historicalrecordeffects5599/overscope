overscope performs three main safety checks every time you use it:

1. **Out-of-Scope Edit Detection**: It compares what the AI agent worked on during its session with the final diff (the list of actual changes made to your files). If the AI touched files that were not part of the original request, overscope flags them clearly.

.

2. **Deleted Test Detection**: Tests are your safety net for catching bugs. overscope monitors whether any test files were deleted or significantly altered during the AI sessionand warns you immediately.

3.. **Dependency Change Detection**: If new external libraries or packages were added to your project's configuration files, overscope lists them so you can decide if they're really needed or if the AI went overboard.

4.. **Completion Claim Verification**: The AI might say "Task complete!" but overscope checks the actual git diff to see if the work matches the claim. If reality doesn't match the report, you'll know right away.
